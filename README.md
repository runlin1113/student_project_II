# student_project_II

> 大三上学期 · 项目实践 2 课程作业仓库

本仓库记录「项目实践 2」课程的阶段性实践产出。目前包含**第三周**的工作内容：围绕一个「上云服务智能体 · 智能体推理模块」展开的文献调研与数据模拟研究。

## 目录结构

```
project_II/
└── week3/                          # 第三周项目实践产出
    ├── 项目实践第三周工作记录.md        # 工作记录（STAR 摘要 + 流程图 + 详细调研全文）
    ├── 项目实践第三周工作记录_assets/   # 工作记录配图（名词表、结构图、方法对比图等 7 张）
    ├── 凌润林第三周文献汇报.pptx        # 第三周文献汇报幻灯片
    ├── 数据模拟文献调研.html           # 数据模拟领域文献调研网页（25 篇论文方法集）
    └── skill/
        └── papers-to-showcase-web/  # 将论文 / 文献笔记聚合为单页展示网站的 WorkBuddy 技能源码
```

## 内容说明

- **第三周工作记录**：以 STAR 框架梳理了「上云服务智能体」中智能体推理与数据模拟的研究脉络，涵盖 SFT / DPO / RL 等训练环节名词、环境与轨迹的关系、数据模拟四类主流方法对比，并定位了两篇与项目关联度高的论文（Cloud Emulator、τ-bench）。
- **文献汇报 PPT**：第三周文献调研的汇报材料。
- **数据模拟文献调研网页**：基于 WorkBuddy 检索生成的单页文献调研网站，汇总了「环境合成 / 轨迹合成 / 评估指标 / 环境复用」四类共 25 篇论文方法集。
- **papers-to-showcase-web 技能**：将上述文献调研聚合为展示网站的 WorkBuddy 技能源码。

## 说明

本仓库内容仅供学习与交流使用。
