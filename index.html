我的工作思路

  1. 一条主线：为组内云模拟器评估搭建文献基础与方法框架。
  2. 统一解读：每篇论文用「五问」拆解（解决什么问题 / 怎么解决 / 为什么有效 / 怎么证明 / 我们的机会点），保证跨论文可比。
  3. 四维方法：以轨迹生成、环境复用、环境生成、基准测评贯穿智能体训练全流程——既标注问题，也对应解法。
  4. 闭环落地：数据集 → 基准 → 指标 → 上线对齐，把「保真度」从宣称变成可量化验证，最终服务组内评测方案。
